This project is an independent exploratory data analysis examining how consumers make decisions in digital retail environments. The core idea is simple but underexplored at the undergraduate level: the clicks, ratings, session durations, and purchase patterns that users leave behind are not random — they are shaped by predictable cognitive shortcuts and psychological biases that behavioral economists have studied for decades. This analysis attempts to surface those patterns from real and simulated data and explain them using established theory.
Three datasets were used. The Amazon Product Reviews Dataset (~3.6 million rows) was analyzed to study rating distributions and social proof dynamics. The Online Retail II Dataset from the UCI Machine Learning Repository (~1.06 million transactions) was used to examine seasonal purchase trends and basket size patterns. A simulated Google Analytics-style session dataset (~85,000 sessions) was constructed in Python to explore the relationship between user engagement and conversion likelihood.
Key findings include a pronounced J-shaped skew in star ratings, with over 52% of reviews rated 5 stars — consistent with Prospect Theory and post-purchase rationalization. Purchase volumes spiked 31% above average in November, reflecting price anchoring around promotional events. Session duration and page depth showed a moderate positive correlation with conversion (r = 0.41), suggesting that engaged browsing reflects deeper stages of the decision-making process.
Tools used include Python, Pandas, NumPy, Matplotlib, and Seaborn. Theoretical frameworks drawn upon include Simon's bounded rationality, Kahneman and Tversky's Prospect Theory, and Cialdini's social proof principle.
This project was completed independently as a portfolio piece to demonstrate foundational data analysis skills including data cleaning, exploratory analysis, statistical interpretation, and research communication.
